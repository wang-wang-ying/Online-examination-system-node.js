# 在线考试管理系统-node.js
### 1、系统功能
在线考试管理系统，采用前后端分离架构，后端基于Node.js + Express + MySQL，前端基于Vue3 + Element Plus + Pinia。系统包含题库管理、考试管理、成绩管 理、考试中心、系统管理五大模块，支持从题目录入、组卷、考试安排、在线答题到成绩 统计的完整考试流程!

· 登录

· 首页

· 考试中心：我的考试 | 在线答题（倒计时、答题卡、自动交卷） | 我的成绩

· 成绩管理：成绩明细（人工阅卷） | 成绩统计（概览卡片、及格率分析）

· 考试管理：试卷管理（组卷、发布） | 考试安排（发布、参考范围设置）

· 题库管理：科目管理 | 题目管理（单选、多选、判断、简答）

· 学生管理：学生列表

· 系统管理：菜单管理 | 角色管理 | 账号管理
